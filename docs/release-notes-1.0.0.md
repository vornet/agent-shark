# AgentShark 1.0.0

AgentShark gives AI agents a headless, local network debugger over MCP. This first stable release supports passive capture, capture-file analysis and explicitly routed HTTP/HTTPS observation with evidence-linked results.

## Downloads and installation

- **Windows 11 x64/ARM64:** run the matching `-setup.exe`. Installation is per-user and connects detected AI client profiles by default. Npcap is a separate optional prerequisite for passive capture; it is not required for proxy/import modes.
- **macOS x64/Apple silicon:** run the matching `.pkg`. The package installs under `/usr/local/lib/agent-shark` and configures the active desktop user's detected client profiles. A system install requires authorization from macOS.
- **Linux x64/ARM64:** install the `.deb` on supported Debian/Ubuntu systems, or extract the `.tar.gz` and run `./install.sh` as your desktop user. The portable installer is per-user. Headless/root package installation may require running the setup utility later as the intended desktop user.
- **Claude Desktop extensions:** matching `.mcpb` bundles offer the client's native extension installation flow. Use either this extension or the system installer's Claude Desktop registration, not both for the same profile.

Setup supports Codex, Claude Desktop, Claude Code, Cursor, VS Code's default profile and existing Windsurf profiles. It preserves unrelated configuration, stores backups and refuses to replace unmanaged or modified entries. Restart clients after installation; their normal trust prompts and organizational policy still apply. Detection uses existing profile directories; clients not yet launched can be selected later with `AgentShark.Setup integrate --clients <client-id>`.

Every downloadable installer/archive has a `.sha256` checksum. Verify the checksum after downloading. These builds are not vendor code-signed or Apple-notarized; native OS reputation/trust prompts can appear. GitHub build provenance, where generated by the release workflow, identifies the producing repository and workflow; it is not an OS publisher certificate.

## Included

- Eleven typed MCP tools for capabilities, observation lifecycle, evidence queries and comparisons.
- Managed PCAP/PCAPNG parsing; bounded TCP reconstruction; HTTP/1 exchanges; DNS, ICMP and TLS handshake metadata.
- Authenticated loopback proxy with exact destination allowlists, CONNECT tunnels and opt-in TLS interception.
- Local SQLite evidence, privacy defaults, resource limits, shutdown finalization and interrupted-session recovery.
- Self-contained .NET 10 binaries; no .NET installation required for native release packages.

## Scope and limitations

HTTP/2, HTTP/3, gRPC decoding, WebSocket frame decoding, passive TLS decryption and IP fragment reassembly are outside v1.0. The HTTP/1 proxy changes connection pooling/timing and cannot transparently handle certificate-pinned applications. Windows process attribution uses socket snapshots and can miss short-lived connections. Proxy TLS interception requires explicit app-scoped trust of the returned CA; no system certificate/proxy changes are automatic.

Capture access depends on the platform, native library/driver and permissions. Data directories are isolated between configured client types; concurrent launches of one client select independent instance directories automatically. Histories/storage quotas are per directory. Do not assume a container sees host traffic. Retained bodies/raw bytes are opt-in and may contain secrets. See the repository README, architecture and security model for complete behavior and operating requirements.
